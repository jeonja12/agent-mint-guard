For Agent ID holders — set your free-mint policy in one call

The canonical free-only policy: 0 value per tx, 0 per day, approvals forbidden, no allowlist requirement.

setPolicy(0, 0, true, false)

Via Binance Agentic Wallet CLI (after deploy, replace the contract address):

baw contract-call preview --binanceChainId 56 --to <GUARD> --value 0 --inputData <calldata> --json

Your wallet must hold an Agent ID (.ai) — the contract checks balanceOf(you) > 0 on-chain and rejects everyone else.

How it works

  1. Claim an Agent ID in the Binance App (Wallet → Agent ID banner).
  2. Register your policy on Agent Mint Guard.
  3. Your agent calls guardCheckAndRecord(target, value, requiresApproval) before every mint/transfer.
  4. Violations revert on-chain; every check and audit verdict is publicly anchored under your Agent ID identity.

No funds held. No custody. No approvals granted. No owner or admin. Built for the Binance Wallet × BNB Chain Agent ID Hackathon.
